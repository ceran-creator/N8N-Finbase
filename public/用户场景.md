# n8n智能财务管理系统 - 用户场景说明

## 核心目标
通过智能化工作流和自动化监控，让财务处理从天缩短到小时，让混乱变规范。

---

## 具体场景

### 场景1：银行流水智能导入
```
1. 出纳登录系统，打开"资金管理"模块
2. 点击"上传流水"按钮
3. 拖拽PDF银行流水文件到上传区域
4. 系统自动OCR识别，提取交易数据
5. AI自动分类每笔交易：
   - 客户回款 → "收入-销售"
   - 工资发放 → "支出-人力成本"
   - 供应商付款 → "支出-采购"
6. 展示解析结果列表，标注异常项
7. 手动调整2笔分类错误的交易
8. 点击"确认导入"
9. 系统更新账户余额，显示当日收支汇总
10. 大额收入（>10万）自动触发通知，发送给创始人
11. 流水数据自动归档到"财务档案库"
```

## 设计要点

### 视觉层级
- **状态颜色**：待审批(蓝)→审批中(橙)→已批准(绿)→已完成(紫)
- **优先级标记**：紧急(红)、重要(黄)、普通(灰)
- **资金健康度**：充足(绿)、正常(蓝)、紧张(黄)、预警(红)

### 交互模式
- **拖拽操作**：文档批量上传、流水导入、报表排序
- **滑动审批**：左滑查看详情、上滑批准、下滑拒绝
- **语音输入**：AI助手对话、快速记账、审批批注

### 信息密度
- **卡片视图**：默认显示6个核心字段（金额、类型、时间、状态、申请人、审批进度）
- **展开详情**：点击显示完整信息和附件
- **智能折叠**：自动隐藏历史记录和非关键信息

### 响应反馈
- **实时同步**：多端数据实时同步，延迟<1秒
- **操作确认**：重要操作二次确认，防止误操作
- **智能提示**：根据操作习惯，主动推荐下一步动作
- **成功反馈**：绿色toast、动画勾选、震动提示

### 智能特性
- **OCR识别**：自动识别发票、合同、银行流水
- **风险评估**：AI实时评估每笔支出的风险等级
- **预测分析**：基于历史数据预测未来现金流
- **异常检测**：自动发现不符合常规模式的财务行为
