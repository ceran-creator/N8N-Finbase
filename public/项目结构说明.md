# n8n智能财务管理系统 - 项目结构说明

## 页面流程

```
用户访问 → index.html (登录页面) → home.html (主工作区)
```

## 文件结构

### 主要页面
- **index.html** - 登录页面（首页）
- **home.html** - 主工作区页面

### 样式文件
- **login-styles.css** - 登录页面样式
- **styles.css** - 主工作区样式

### 脚本文件
- **login-script.js** - 登录页面交互逻辑
- **script.js** - 主工作区交互逻辑

### 设计资源
- **设计图/** - 包含所有UI设计图片资源

## 页面功能

### 登录页面 (index.html)
- **入口页面**: 用户首先看到的页面
- **登录方式**: Google、邮箱、Founder注册
- **设计特色**: 左右分栏布局，淡蓝紫色主题
- **跳转目标**: 登录成功后跳转到 home.html

### 主工作区 (home.html)
- **功能页面**: 登录后的主要工作界面
- **核心模块**: 资金、核算、监控三大功能模块
- **导航功能**: 侧边栏导航，聊天面板
- **返回登录**: "Continue with phone"按钮返回登录页面

## 技术特点

### 设计系统
- **色彩**: 淡蓝紫色变主题 (#D9E4FF, #EDDDFF)
- **布局**: 响应式设计，适配多设备
- **交互**: Apple级别的用户体验

### 开发规范
- **HTML5**: 语义化标签
- **CSS3**: 现代布局和动画
- **JavaScript**: ES6+语法，模块化设计

## 使用说明

1. **启动**: 直接打开 index.html 开始使用
2. **登录**: 选择登录方式完成身份验证
3. **工作**: 在主工作区进行财务管理操作
4. **切换**: 可随时返回登录页面切换账户

## 浏览器支持

- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

## 注意事项

1. 确保所有设计图片资源路径正确
2. 登录功能需要后端API支持
3. 建议在本地服务器环境下运行
