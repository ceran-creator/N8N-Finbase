# n8n智能财务管理系统 - 登录页面（首页）

## 页面概述

登录页面作为系统首页，采用左右分栏布局，遵循Apple级别的设计严谨度，使用淡蓝紫色主题色彩系统。用户首先看到登录页面，登录成功后进入主工作区。

## 设计特色

### 色彩系统
- **主色调**: 淡蓝紫色变 (#D9E4FF, #EDDDFF)
- **辅助色**: 淡紫色系，确保WCAG对比度达标
- **整体风格**: 低饱和度，现代简约

### 布局结构

#### 左侧登录渠道区域
- **Logo区域**: 显示n8n财务品牌标识
- **欢迎信息**: "欢迎回来"标题和副标题
- **登录按钮组**:
  - Sign in with Google (Google登录)
  - Sign in with email (邮箱登录)
  - Founder registration (Founder注册)
- **登录渠道图片**: 展示登录渠道相关图片

#### 右侧广告图区域
- **广告图片**: 展示产品广告图片
- **渐变背景**: 与左侧形成视觉平衡

## 功能特性

### 交互功能
1. **Google登录**: 模拟OAuth流程（开发中）
2. **邮箱登录**: 完整的邮箱密码登录表单
3. **Founder注册**: 企业用户注册流程
4. **忘记密码**: 密码重置功能
5. **表单验证**: 实时输入验证和错误提示

### 响应式设计
- **桌面端**: 左右分栏布局
- **平板端**: 上下布局，保持视觉平衡
- **移动端**: 单列布局，优化触摸体验

### 动画效果
- **页面加载**: 淡入上移动画
- **按钮交互**: 悬停和点击反馈
- **模态框**: 平滑的打开关闭动画
- **通知系统**: 滑入滑出效果

## 技术实现

### 文件结构
```
index.html          # 登录页面HTML结构（首页）
home.html           # 主工作区HTML结构
login-styles.css    # 登录页面样式
login-script.js     # 登录页面交互逻辑
script.js           # 主工作区交互逻辑
styles.css          # 主工作区样式
```

### 主要技术
- **HTML5**: 语义化标签，无障碍访问
- **CSS3**: Flexbox布局，CSS变量，动画效果
- **JavaScript**: ES6+语法，模块化设计
- **响应式**: 移动优先设计理念

### 浏览器兼容性
- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+

## 使用说明

1. 打开系统后首先看到登录页面（首页）
2. 选择登录方式：
   - Google登录：点击"Sign in with Google"
   - 邮箱登录：点击"Sign in with email"
   - 注册账户：点击"Founder registration"
3. 填写相应信息完成登录或注册
4. 登录成功后自动跳转到主工作区（home.html）
5. 在主工作区可以点击"Continue with phone"按钮返回登录页面

## 设计规范

### 间距系统
- 使用8px基础网格系统
- 统一的间距变量管理

### 字体系统
- 主字体：Inter
- 字号：12px-36px，6个层级
- 字重：300-700，5个层级

### 圆角系统
- 小圆角：6px
- 中圆角：12px
- 大圆角：24px
- 超大圆角：32px

### 阴影系统
- 4个层级的阴影深度
- 统一的阴影颜色和模糊度

## 注意事项

1. 所有图片路径需要确保正确
2. 表单验证需要后端API支持
3. 登录状态管理需要与主页集成
4. 密码重置功能需要邮件服务支持
