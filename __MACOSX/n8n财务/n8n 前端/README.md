# n8n智能财务管理系统 - 前端主页

## 项目概述

这是n8n智能财务管理系统的前端主页实现，专为10-50人初创公司打造的全流程财务自动化平台。采用Apple级别的设计标准，提供简洁高效的用户体验。

## 设计特色

### 🎨 视觉设计
- **主色调**: 浅蓝紫色渐变主题 (`#D9E4FF` → `#EDDDFF`)
- **设计风格**: Apple级别的严谨设计，简洁现代
- **响应式布局**: 完美适配桌面、平板、手机设备
- **动画效果**: 流畅的过渡动画和交互反馈

### 🏗️ 页面结构
```
├── Header (顶部导航栏)
├── Main Layout
│   ├── Sidebar (左侧导航)
│   │   ├── Logo区域
│   │   └── 导航菜单 (首页、文档管理、历史记录、收藏)
│   ├── Main Content (主工作区)
│   │   ├── 欢迎区域
│   │   ├── 核心功能模块 (4个模块卡片)
│   │   └── 快速操作区域
│   └── Chat Panel (右侧聊天面板)
└── AI财务助手对话框
```

### 🚀 核心功能模块

1. **智能文档管理中心**
   - 制度库管理、OCR识别、自动归档
   - 实时统计：文档总数、本月新增

2. **资金流转自动化引擎**
   - 流水导入、实时监控、分级审批
   - 实时数据：今日流水、待审批数量

3. **财务报表生成系统**
   - 多频次报表、预算分析、现金流预测
   - 执行情况：本月报表、预算执行率

4. **合规监控保障体系**
   - 税务申报、审批痕迹、制度监测
   - 合规状态：检查完成率、风险预警

## 技术实现

### 前端技术栈
- **HTML5**: 语义化标签，无障碍访问
- **CSS3**: 现代CSS特性，Flexbox/Grid布局
- **JavaScript ES6+**: 模块化编程，面向对象设计
- **Font Awesome**: 图标库
- **Google Fonts**: Inter字体

### 设计系统
- **颜色系统**: 完整的色彩规范，支持主题切换
- **字体系统**: 多级字体大小和权重
- **间距系统**: 统一的间距规范
- **组件库**: 可复用的UI组件

### 响应式设计
- **桌面端**: 1200px+ 完整布局
- **平板端**: 768px-1024px 适配布局
- **手机端**: <768px 移动优先设计

## 使用方法

### 本地运行
1. 下载所有文件到本地目录
2. 用现代浏览器打开 `index.html`
3. 无需服务器，可直接运行

### 功能说明

#### 模块卡片交互
- 点击任意功能模块卡片可进入对应功能页面
- 悬停效果提供视觉反馈
- 点击动画增强用户体验

#### 快速操作
- **上传流水**: 打开文件上传对话框
- **新建申请**: 打开申请表单对话框
- **生成报表**: 打开报表配置对话框

#### AI聊天助手
- 支持关键词智能回复
- 实时对话体验
- 可询问余额、流水、审批、报表、风险等问题

#### 导航菜单
- 左侧导航栏支持页面切换
- 当前页面高亮显示
- 响应式折叠菜单
